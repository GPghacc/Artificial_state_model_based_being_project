# 시험 목록

장의 역할: 정신적 에너지를 느끼는 감각 + 자극 패턴의 재현. 에너지가 몰린 곳에 연산(주의)을 더 주기 위한 지도.

## 지금 돌릴 수 있는 것 (`field_role_tests.py`)

| 시험 | 묻는 것 |
|---|---|
| A 위치 | 자극이 몰린 곳에 에너지 봉우리가 생기는가 |
| B 섞임 | 가까운 두 자극이 하나의 봉우리로 합쳐지는가 |
| C 에너지 | 전체 에너지가 자극의 양을 재는 눈금이 되는가 |
| D 잔향 | 자극이 끊긴 뒤 봉우리가 얼마나 남는가 |
| E 따라감 | 몰린 곳이 옮겨가면 봉우리가 얼마나 빨리 따라가는가 |

매질 설정을 바꿀 때마다 `--set field.c2=0.12 --tag 이름`처럼 돌려서 `results/`의 이전 결과와 비교한다.

## 기능이 생기면 더할 것

| 필요한 기능 | 더할 시험 |
|---|---|
| 판단 모듈 (에너지 봉우리 → 주의 이동) | 주의가 봉우리를 따라가는가. 자극이 잠깐 끊겨도 깜빡이지 않는가 |
| 주의 되먹임 (주의 → 입력 증폭 → 에너지) | 한곳에 붙어버리지 않는가. 더 큰 자극이 다른 곳에 생기면 옮겨가는가 |
| 무뎌짐 (칸 단위, 변화 없을 때만) | 안 변하는 자극은 흐려지고 변하는 자극은 남는가. 오래 봐도 구역 전체가 닫히지 않는가 |
| 연산 할당 (주의 = 해상도·처리량) | 주의를 준 곳의 처리가 실제로 더 촘촘한가. 주의 밖도 최소량은 처리되는가 |
| 화면 등 실제 입력 | 화면에서 변한 자리와 봉우리 자리가 일치하는가 |
| 매질 학습 (W) | 자주 함께 울린 곳 사이로 물결이 더 잘 퍼지는가. 며칠 돌려도 폭주하거나 굳지 않는가 |
| 내부 감각 (에너지를 다시 느낌) | 전체 에너지가 내부 감각 구역에 눈금으로 들어가는가 |
| 읽기 층 | 서로 다른 상황이 구분되는 패턴을 만드는가. 같은 상황이 다시 오면 비슷한 패턴이 나오는가 |

## 참고용 (역할과 맞지 않아 기준으로 쓰지 않음)

`baseline_benchmark.py`, `stimulus_count.py`: 장을 기억 장치로 보고 잰 시험. 자극의 순서나 출처를 맞히는 능력은 장의 역할이 아니다.
