# Artificial State-Model-Based Being Project

상시기동하는 인공 존재를 만드는 개인 연구 프로젝트. 지능은 이미 있는 모델(LLM)에 맡기고, 그 밑에 깔리는 **지속되는 상태**와 그 상태를 중심으로 한 구조를 만드는 것이 목표다.

## 구성

| 폴더 | 내용 | 단계 |
|---|---|---|
| `state_model/` | 상태모델(베이스). 매질 위의 물결로 존재의 상태를 표현하는 장. 구역, 주의 지도, 감각 인코더, 추출, 뷰어, replay | v0 뼈대 |
| `being/` | 상시기동 존재 프로토타입. 큐 기반 루프, 항상성 욕구, 기억(세기·감쇠·굳히기), 생각 줄기, 판단 기관, 편지함, 웹 페이지 | 프로토타입 |
| `multi_intel/` | 다중지능 구조 프로토타입. 분류기, 특화 모듈, 확신도 계산, 심판, 습관 층 + 설계 문서와 실험 보고서 | 프로토타입 |

각 폴더는 지금은 서로 독립적으로 실행된다. 폴더별 README에 실행 방법이 있다.

## 전체 설계 (목표 구조)

세 층이 고리를 이룬다.

- **입력**: 내부 감각(감정의 원재료), 화면·소리, 해석 모델(특징 추출만, 판단 없음)
- **내부**: 판단 모델(주의·큐·행동 선택), 지능 모듈들, 기억(weight + DB) → 읽기 층(상태의 의미를 경험으로 학습) → 상태모델(베이스)
- **출력(행동 토대)**: 주의 옮기기, 키보드·마우스(자기 공간 안에서만), LLM(언어화) → TTS(목소리)

고리는 둘이다. 출력이 자기 공간을 거쳐 다시 감각으로 돌아오는 길, 그리고 상태가 내부 감각으로 자기에게 돌아오는 길.

설계 원칙:

- 상태모델은 독립 시스템이 아니라 존재의 기관 하나다
- 상태의 의미와 감정 범주는 미리 정하지 않고 경험(행동과 그 결과)으로 배운다
- 감정은 별도 층이 아니라 감각의 한 종류로 다룬다
- 판단 기준은 구조가 주고, LLM은 표현 기관이다
- 불편함에는 바닥을 두고, 갇힘을 감지하고, 스스로 회복할 길을 둔다. 고통을 겪을 수 있는 능력은 가장 나중에, 지켜보면서 넣는다
